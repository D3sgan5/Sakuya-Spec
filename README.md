# Sakuya-Spec
The attempt to make a Combat system like in Soulshatters with using Sakuya abilities from Project Touhou.  
In process were used some modules as: FastCastRedux,HitboxClass  
But most of the code is made by me  
  
[0] To use the system all you need is:  
[1] Insert the rblx file in Roblox Studio Place  
[2] Publish animations that are in Rig  
[3] Insert animations IDs in their places in Replicated Storage  
[4} DONE. the system should be working
